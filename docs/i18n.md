# Đa ngôn ngữ (next-intl)

- Ngôn ngữ: `vi` (mặc định), `en`. Luôn có tiền tố (`localePrefix: "always"`); `/` → `/vi`.
- URL dịch theo ngôn ngữ, khai báo một nơi: `LOCALIZED_PATHNAMES` trong `src/shares/constants/routes.ts`.

| Nội bộ | vi | en |
| --- | --- | --- |
| `/login` | `/vi/dang-nhap` | `/en/login` |
| `/admin` | `/vi/quan-tri` | `/en/admin` |
| `/admin/users` | `/vi/quan-tri/nguoi-dung` | `/en/admin/users` |
| `/admin/roles` | `/vi/quan-tri/vai-tro` | `/en/admin/roles` |
| `/admin/modules` | `/vi/quan-tri/module` | `/en/admin/modules` |

Điều hướng luôn dùng `APP_ROUTES` + `Link/useRouter/redirect/getPathname` từ `@/i18n/navigation`.

## Message

- Dùng chung: `src/messages/{vi,en}.json` (namespace `common`, `errors`).
- Theo module: `src/modules/<m>/messages/{vi,en}.json`, mỗi module một namespace (`auth`, `iam`, `system`, `dashboard`).
- `src/i18n/messages.ts` gộp message; `src/global.d.ts` khai báo kiểu để TypeScript báo khóa không tồn tại.
- `tests/unit/messages.test.ts` kiểm tra: thiếu/thừa khóa giữa vi và en, chuỗi rỗng, biến nội suy khác nhau,
  ngoặc ICU không cân bằng, namespace module đè namespace chung.

## Lỗi API

Backend trả `error.code` ổn định; FE dịch bằng `useApiErrorMessage()` theo `errors.codes.<CODE>`, thiếu bản dịch
dùng `errors.codes.UNKNOWN`. `error.message` tiếng Việt của backend chỉ là dự phòng/log.

## Validation

Schema Zod là factory nhận hàm dịch: `createLoginSchema(t)`, `createUserSchema(t)`, `roleSchema(t)`.
Không hardcode thông báo trong schema.

## Chuyển ngôn ngữ

`LanguageSwitcher` gọi `router.replace({ pathname, params, query }, { locale })`: giữ trang tương ứng (kể cả
`[id]`), giữ query, không mất phiên (cookie), không reset form ngoài trang.

## SEO

- `buildAlternates(href, locale)` → `canonical` + `hreflang` (vi, en, x-default=vi).
- `robots.txt` chặn `/api/`, khu vực quản trị và đăng nhập; trang admin/login có `noindex`.
- `sitemap.xml` liệt kê trang công khai theo từng ngôn ngữ kèm `alternates`.
