1. Tổng quan

Foundation cho website cá nhân toannx.com: backend Django REST (backend/) và frontend Next.js 16 (frontend/) chạy, build, test và deploy độc lập. Đã có đăng nhập/đăng xuất/refresh xoay vòng, phân quyền RBAC, quản lý người dùng/vai trò/quyền, module registry, i18n vi/en, admin layout responsive và logo chữ T. Chưa có module nghiệp vụ (Analytics, Links, Payment QR, Novel, CMS) theo đúng phạm vi.

3. Kiến trúc

Trình duyệt ──► toannx.com (Next.js)
                 ├─ src/proxy.ts : next-intl + kiểm tra lạc quan cookie toannx_session
                 └─ rewrite /api/v1/* ──► api.toannx.com (Django) ──► Neon PostgreSQL

Trình duyệt chỉ thấy một origin ⇒ cookie host-only, không cần CORS ở production. Chi tiết: docs/architecture.md.

Quyết định Lý do
Một file config/settings.py, khác biệt qua biến môi trường Theo yêu cầu của bạn trong phiên làm việc (chuẩn Django, không làm rộng)
Scaffold bằng CLI: uv init, django-admin startproject config ., startapp, create-next-app, shadcn init/add Theo yêu cầu: không dựng tay
App Django bố cục phẳng (models.py, services.py, ...) thay vì mỗi class một file Gần chuẩn Django, ít file rỗng; tầng View/Service/Repository/Selector vẫn tách rõ
Không gắn Django admin (/admin là admin của Next.js) Giảm bề mặt tấn công; quyền đi qua IAM
Tắt cacheComponents (mặc định của create-next-app 16.4) Admin render phía client; bật lại khi có trang public cần cache

4. Audit source tham khảo

Đã đọc trực tiếp D:\projects\PMS\PMS-AZ-BE và D:\Medoly\frontend\src\shares\components (chỉ đọc). Chi tiết: docs/reference-audit.md.

  • PMS kế thừa ý tưởng: ContextVar cho user, assertion test dùng chung, factory_boy, tách serializer request/response.
  • PMS sửa lại: audit ngầm trong save() kèm 3 truy vấn mỗi lần lưu; ContextVar không bao giờ reset; except Exception: pass trong middleware; 10 lớp response trùng nhau; ErrorCode có khóa trùng và giá trị tuple; quyền dựa user_permissions; MasterViewBase với danh sách quyền rỗng = cho phép.
  • Medoly kế thừa: PasswordInput, EmptyState, ErrorState, Pagination, LanguageSwitcher (đều chuẩn hóa về token theme; LanguageSwitcher sửa lỗi mất query/params). Primitive UI sinh lại bằng shadcn add.
  • Tiptap: chưa tích hợp; đã ghi nhận cách tích hợp cho Novel/CMS.

15. Bước tiếp theo

  1. Tạo project Vercel + Neon, cấu hình biến môi trường, migrate, deploy thử và xác minh cookie/CSRF/IP trên production.
  2. Thêm Vercel Cron dọn auth_session, auth_refresh_token, auth_rate_limit_bucket.
  3. Trang “Phiên đăng nhập của tôi” (API đã có) và trang đổi mật khẩu cá nhân.
  4. E2E cho thao tác CRUD người dùng/vai trò và kích thước tablet.
  5. CI (GitHub Actions) chạy scripts/check-all.sh với service PostgreSQL.
  6. Module nghiệp vụ đầu tiên theo hướng dẫn “Thêm module mới” trong AGENTS.md.
